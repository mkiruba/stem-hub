# VEX Robotics & VEXcode VR

**Best for:** ages 11–18, competitions, school classrooms, zero-budget digital twins
**Cost:** £0 for VR Simulator, high for physical competition kits
**Languages:** VEXcode Blocks (Scratch-based) · Python · C++
**Buy:** [VEX Robotics UK](https://www.vexrobotics.com/en-gb)

With the retirement of LEGO MINDSTORMS and SPIKE, **VEX Robotics** has become the dominant platform for competitive school robotics. It spans from primary school (VEX GO / IQ) to university level (VEX V5 / EXP).

Crucially for this repository, VEX provides an incredible **free** browser-based simulator called VEXcode VR. It allows students to program virtual robots in 3D environments without needing any physical hardware.

---

## VEXcode VR (Free Virtual Simulator)

> **[VEXcode VR Web Editor](https://vr.vex.com/)** — `Foundation` `Intermediate` `Simulator`
> Program a virtual robot in a 3D playground to solve mazes, clean up obstacles, and draw with a virtual pen. Works entirely in the browser. Parts needed: None (browser-based).

> **[VEXcode VR Computer Science Level 1](https://education.vex.com/vr/)** — `Foundation` `Curriculum`
> Free curriculum mapped to the VR simulator, teaching sequences, loops, conditionals, and variables using block coding. Parts needed: None.

> **[VEXcode VR Python Curriculum](https://education.vex.com/vr-python/)** — `Intermediate` `Curriculum`
> A structured transition from block coding to text-based Python using the virtual robot environments. Parts needed: None.

## Physical Hardware & Competitions

> **[VEX IQ Education](https://education.vex.com/iq/)** — `Foundation` `Intermediate` `Curriculum`
> Snap-together plastic robotics (similar to LEGO Technic) designed for ages 11-14. Curriculum covers mechanical design and programming. Parts needed: VEX IQ kit.

> **[VEX V5 System](https://education.vex.com/v5/)** — `Advanced` `Curriculum`
> Metal construction system for ages 14-18+, utilizing powerful smart motors, vision sensors, and C++ programming for advanced competition robotics. Parts needed: VEX V5 kit.

> **[VEX Robotics Competition (VRC)](https://www.roboticseducation.org/)** — `Reference`
> Information on the global competition tracks managed by the REC Foundation. Parts needed: See tutorial for details.

## Project ideas by track

> **[Castle Crasher (VR Blocks)](https://education.vex.com/vr/lessons/lesson-2/)** — `Foundation` `Tutorial`
> Use loops and bumper sensors in VEXcode VR to program a robot to autonomously push virtual castles off a platform. Parts needed: None.

> **[Disk Maze (VR Python)](https://education.vex.com/vr-python/lessons/lesson-4/)** — `Intermediate` `Tutorial`
> Write Python code utilizing the robot's front eye sensor and distance sensor to navigate a complex colored maze autonomously. Parts needed: None.

**Foundation ideas (VEXcode VR):** draw a square with the pen tool · drive through a grid map · use bumper sensors for a room-ba style vacuum

**Intermediate ideas (VEX IQ):** line following using color sensors · sorting cubes by color using a motorized arm · remote control arcade drive

**Advanced ideas (VEX V5):** PID motor control · object tracking and alignment using the V5 Vision Sensor · autonomous 15-second competition routines
