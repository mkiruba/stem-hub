# Arduino & Adafruit

**Best for:** ages 13+, wearables, the deepest tutorial library anywhere
**Cost:** ~£10–30 per board
**Languages:** CircuitPython · Arduino C++ · MicroPython
**Buy:** [Adafruit](https://www.adafruit.com/) (US) · [The Pi Hut](https://thepihut.com/collections/adafruit) (UK stockist) · [Pimoroni](https://shop.pimoroni.com/) · [RS](https://uk.rs-online.com/web/)

Two ecosystems, treated together because they overlap heavily in practice.

**Arduino** is the older, larger world: an enormous body of tutorials, shields and community code, built around C++. If a project exists anywhere on the internet, an Arduino version of it probably exists.

**Adafruit** makes distinctive hardware — Circuit Playground, Feather, QT Py, NeoPixels, STEMMA QT sensors — but its real contribution to education is [**learn.adafruit.com**](https://learn.adafruit.com/), which is very likely the single largest collection of free, well-produced electronics tutorials in existence. Most of it is Creative Commons licensed, meaning teachers can legally adapt it.

## Official & free

> **[Adafruit Learning System](https://learn.adafruit.com/)** — `Foundation` `Intermediate` `Advanced` `Tutorial`
> Thousands of guides, each with parts list, wiring diagram, full code and photos. Filterable by category and difficulty. Genuinely exceptional. Bookmark it. Parts needed: See tutorial for details.

> **[Welcome to CircuitPython](https://learn.adafruit.com/welcome-to-circuitpython)** — `Intermediate` `Tutorial`
> The canonical starting guide. CircuitPython's model — the board mounts as a USB drive, you edit `code.py`, it reruns instantly — removes the whole compile-upload cycle. For beginners this is a significant advantage over Arduino C++. Parts needed: See tutorial for details.

> **[circuitpython.org](https://circuitpython.org/)** — `Reference`
> Downloads, supported boards, and the library bundle. Parts needed: See tutorial for details.

> **[Circuit Playground Express guides](https://learn.adafruit.com/category/circuit-playground)** — `Foundation` `Tutorial`
> Sensors, LEDs, speaker and accelerometer all onboard, alligator-clip pads, and MakeCode block support. The closest Adafruit equivalent to a micro:bit, and an excellent classroom board. Parts needed: See tutorial for details.

> **[Arduino Docs](https://docs.arduino.cc/)** — `Intermediate` `Reference`
> Official language reference and board documentation. Parts needed: See tutorial for details.

> **[Arduino Project Hub](https://projecthub.arduino.cc/)** — `Foundation` `Intermediate` `Tutorial`
> Community projects with code and wiring. Parts needed: See tutorial for details.

> **[Tinkercad Circuits](https://www.tinkercad.com/circuits)** — `Foundation` `Simulator`
> Free browser simulation of Arduino plus components, with block coding available. Superb for classrooms with more students than boards. Parts needed: See tutorial for details.

> **[Seeed Studio Grove Beginner Kit for Arduino](https://wiki.seeedstudio.com/Grove-Beginner-Kit-For-Arduino/)** — `Foundation` `Reference`
> Ten sensors and modules pre-wired to a single PCB — no breadboard, no jumper wires, so miswiring simply isn't possible for the first few weeks. A gentler on-ramp than a bare Arduino Uno for a learner moving on from micro:bit crocodile clips. Stocked via [The Pi Hut](https://thepihut.com/) and [Pimoroni](https://shop.pimoroni.com/). Parts needed: Grove Beginner Kit board.

> **[Wokwi](https://wokwi.com/)** — `Intermediate` `Simulator`
> More capable simulation covering Arduino, ESP32 and Pico. Free, no install. Parts needed: See tutorial for details.

## Project ideas by track

**Foundation:** Circuit Playground light-reactive NeoPixel patterns · sound-triggered effects · shake-to-roll dice · capacitive touch instrument

**Intermediate:** LED sneakers or a light-up costume (Becky Stern's guides) · plant monitor posting to a phone · IR remote-controlled robot · ESP32 WiFi weather display · MIDI foot controller · door sensor with notification

**Advanced:** LoRa long-range sensor network · CircuitPython driver written from a datasheet for an unsupported sensor · custom Feather-format PCB in KiCad · on-device ML with [Edge Impulse](https://edgeimpulse.com/) (free developer tier) · quadruped with inverse kinematics

## Practical notes for UK buyers

Adafruit ships from the US. Once postage and duty are counted, check [The Pi Hut](https://thepihut.com/collections/adafruit) and [Pimoroni](https://shop.pimoroni.com/) first — both stock much of the Adafruit range domestically. The tutorials are free regardless of where you buy the parts, and most work fine with generic equivalents.

**STEMMA QT / Qwiic** connectors are worth seeking out for classroom use specifically. They're keyed I²C plugs, so sensors physically cannot be miswired. This eliminates the single most common cause of "it doesn't work and we don't know why".
