# AI & Machine Vision

**Best for:** ages 13+, facial recognition, object tracking, edge machine learning
**Cost:** ~£45 (HuskyLens) to £100+ (Raspberry Pi AI kit)
**Languages:** Python · MakeCode Blocks
**Buy:** [The Pi Hut](https://thepihut.com/) · [Pimoroni](https://shop.pimoroni.com/)

Artificial Intelligence and machine vision can seem completely out of reach for a 12-year-old on a £15 micro:bit. However, "Edge AI" modules have changed this. Instead of a microcontroller trying to process heavy video feeds, dedicated AI cameras process the video locally and simply send the results (e.g., "I see a face at X,Y coordinates") to the microcontroller over simple wires.

## DFRobot HuskyLens (No-Code/Low-Code AI)

> **[HuskyLens Official Wiki](https://wiki.dfrobot.com/HUSKYLENS_V1.0_SKU_SEN0305_SEN0336)** — `Foundation` `Intermediate` `Reference`
> HuskyLens is an easy-to-use AI machine vision sensor with a built-in screen. It can learn to recognize faces, track colors, and read QR codes with the press of a single button. Parts needed: HuskyLens, micro:bit or Arduino.

> **[MakeCode Extension for HuskyLens](https://github.com/DFRobot/pxt-huskylens)** — `Foundation` `GitHub`
> Use block coding to make your micro:bit robot react to what the HuskyLens sees. Parts needed: micro:bit, HuskyLens, robotics chassis.

## Raspberry Pi AI Kit (Advanced Neural Networks)

> **[Raspberry Pi AI Kit Documentation](https://www.raspberrypi.com/documentation/accessories/ai-kit.html)** — `Advanced` `Reference`
> For older students, the Hailo-8L M.2 accelerator combined with a Raspberry Pi 5 allows running full real-time neural networks (like object detection and pose estimation) in Python at 30+ frames per second. Parts needed: Raspberry Pi 5, AI Kit, Pi Camera.

## Project ideas by track

**Foundation ideas (HuskyLens + micro:bit):** an interactive pet robot that only follows its owner's face · a smart barrier that opens only when it reads an authorized QR code

**Intermediate ideas (HuskyLens + Arduino):** an automated turret that tracks specific colored objects · a line-following robot that recognizes intersections and street signs

**Advanced ideas (Raspberry Pi + AI Kit):** real-time traffic monitoring camera that counts cars vs bicycles · posture correction monitor that tracks human skeletal joints in real time
