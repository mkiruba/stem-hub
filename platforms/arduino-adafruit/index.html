    Arduino & Adafruit

    Best for: ages 13+, wearables, the deepest tutorial library anywhere Cost: ~£10–30 per board Languages: CircuitPython · Arduino C++ · MicroPython Buy: Adafruit (US) · The Pi Hut (UK stockist) · Pimoroni · RS

    Two ecosystems, treated together because they overlap heavily in practice.

    Arduino is the older, larger world: an enormous body of tutorials, shields and community code, built around C++. If a project exists anywhere on the internet, an Arduino version of it probably exists.

    Adafruit makes distinctive hardware — Circuit Playground, Feather, QT Py, NeoPixels, STEMMA QT sensors — but its real contribution to education is learn.adafruit.com, which is very likely the single largest collection of free, well-produced electronics tutorials in existence. Most of it is Creative Commons licensed, meaning teachers can legally adapt it.

    Official & free

    Adafruit Learning System — Foundation Intermediate Advanced Tutorial Thousands of guides, each with parts list, wiring diagram, full code and photos. Filterable by category and difficulty. Genuinely exceptional. Bookmark it. Parts needed: See tutorial for details.

    Welcome to CircuitPython — Intermediate Tutorial The canonical starting guide. CircuitPython's model — the board mounts as a USB drive, you edit code.py, it reruns instantly — removes the whole compile-upload cycle. For beginners this is a significant advantage over Arduino C++. Parts needed: See tutorial for details.

    circuitpython.org — Reference Downloads, supported boards, and the library bundle. Parts needed: See tutorial for details.

    Circuit Playground Express guides — Foundation Tutorial Sensors, LEDs, speaker and accelerometer all onboard, alligator-clip pads, and MakeCode block support. The closest Adafruit equivalent to a micro:bit, and an excellent classroom board. Parts needed: See tutorial for details.

    Arduino Docs — Intermediate Reference Official language reference and board documentation. Parts needed: See tutorial for details.

    Arduino Project Hub — Foundation Intermediate Tutorial Community projects with code and wiring. Parts needed: See tutorial for details.

    Tinkercad Circuits — Foundation Simulator Free browser simulation of Arduino plus components, with block coding available. Superb for classrooms with more students than boards. Parts needed: See tutorial for details.

    Wokwi — Intermediate Simulator More capable simulation covering Arduino, ESP32 and Pico. Free, no install. Parts needed: See tutorial for details.

    Video

    Paul McWhorter — Intermediate Video Structured, numbered lesson series with homework assignments at the end of each. The closest thing to an actual free course on YouTube, and unusually well suited to a self-directed teenager. Separate series for Arduino, Raspberry Pi and Python. Parts needed: See tutorial for details.

    DroneBot Workshop — Intermediate Advanced Video Thorough, patient, excellent on motor drivers and sensors. Written companions at dronebotworkshop.com. Parts needed: See tutorial for details.

    Adafruit YouTube — Intermediate Video John Park's Workshop and Ask an Engineer are the highlights. Parts needed: See tutorial for details.

    Becky Stern — Intermediate Video Wearables, e-textiles and soft circuits. A distinctly different entry point that reaches learners who bounce off robot-and-rover framing entirely. Parts needed: See tutorial for details.

    GreatScott! — Intermediate Advanced Video Electronics fundamentals and component theory, short and dense. Parts needed: See tutorial for details.

    Andreas Spiess — Advanced Video ESP32, IoT, LoRa, sensor accuracy. Rigorous — he measures things properly rather than assuming. Parts needed: See tutorial for details.

    Blogs & tutorial sites

    Random Nerd Tutorials — Intermediate Tutorial The best free ESP32/ESP8266 resource. Hundreds of complete IoT projects. Parts needed: See tutorial for details.

    SparkFun Learn — Foundation Intermediate Tutorial Strong on fundamentals, with good explanatory diagrams. Their "concepts" tutorials on voltage, current and logic levels are excellent teaching aids. Parts needed: See tutorial for details.

    Hackster.io — Intermediate Blog Large community project database across every platform. Parts needed: See tutorial for details.

    Instructables — Circuits — Foundation Intermediate Blog Variable quality, huge quantity. Good for inspiration; verify wiring independently. Parts needed: See tutorial for details.

    adafruit — GitHub Hundreds of repos: CircuitPython itself, every sensor driver, and the Learn guide source code — every code example from every tutorial, in one repository. Parts needed: See tutorial for details.

    adafruit/circuitpython — Advanced GitHub A friendly fork of MicroPython. Well-documented contribution process, and a realistic target for a first open-source pull request. Parts needed: See tutorial for details.

    arduino/Arduino — Advanced GitHub

    Lembed/Awesome-arduino — GitHub Curated libraries and projects index. Parts needed: See tutorial for details.

    Project ideas by track

    Foundation: Circuit Playground light-reactive NeoPixel patterns · sound-triggered effects · shake-to-roll dice · capacitive touch instrument

    Intermediate: LED sneakers or a light-up costume (Becky Stern's guides) · plant monitor posting to a phone · IR remote-controlled robot · ESP32 WiFi weather display · MIDI foot controller · door sensor with notification

    Advanced: LoRa long-range sensor network · CircuitPython driver written from a datasheet for an unsupported sensor · custom Feather-format PCB in KiCad · on-device ML with Edge Impulse (free developer tier) · quadruped with inverse kinematics

    Practical notes for UK buyers

    Adafruit ships from the US. Once postage and duty are counted, check The Pi Hut and Pimoroni first — both stock much of the Adafruit range domestically. The tutorials are free regardless of where you buy the parts, and most work fine with generic equivalents.

    STEMMA QT / Qwiic connectors are worth seeking out for classroom use specifically. They're keyed I²C plugs, so sensors physically cannot be miswired. This eliminates the single most common cause of "it doesn't work and we don't know why".
