    Blogs & magazines

    Written resources, all free. Written material beats video for anything you follow with your hands busy.

    Free magazines (the most undervalued resources here)

    Raspberry Pi Official Magazine — Foundation Intermediate Advanced Every issue free as a PDF, including the complete archives of The MagPi and HackSpace. That's well over a decade of monthly issues — hundreds of them, thousands of projects, entirely free and legal to download. The Foundation also publishes full project books as free PDFs. Parts needed: See tutorial for details.

    If you're building a club library on no budget, this is the whole library.

    Hello World — Curriculum Computing education magazine for teachers, free as PDF, free in print to UK educators. Pedagogy rather than projects — how to teach this stuff, what misconceptions to expect, what the research says. Parts needed: See tutorial for details.

    Tutorial sites

    Adafruit Learning System — Foundation Intermediate Advanced Very likely the largest free electronics tutorial library in existence. Every guide has parts list, wiring diagram, complete code and photographs. Most content is Creative Commons licensed, so teachers can legally adapt it for their own materials. Source code for every guide is on GitHub. Parts needed: See tutorial for details.

    Raspberry Pi Foundation Projects — Foundation Intermediate Advanced Several hundred structured, sequenced projects. Creative Commons, translated into dozens of languages, and entirely open-sourced so you can fork and adapt the curriculum. Parts needed: See tutorial for details.

    Random Nerd Tutorials — Intermediate The deepest free ESP32/ESP8266/Pico library. Some paid ebooks exist, but the free tier alone runs to hundreds of complete projects. Parts needed: See tutorial for details.

    SparkFun Learn — Foundation Intermediate Best free written explanations of fundamentals, with genuinely good diagrams. The concepts tutorials (voltage, pull-up resistors, logic levels) work directly as lesson material. Parts needed: See tutorial for details.

    Pimoroni Learn — Intermediate UK-based, matched to Pimoroni hardware, well-written. Parts needed: See tutorial for details.

    The Pi Hut tutorials — Foundation Intermediate UK parts lists, which removes substitution guesswork for British readers. Parts needed: See tutorial for details.

    Kitronik Resources — Foundation UK, classroom-oriented, with downloadable lesson plans. Parts needed: See tutorial for details.

    All About Circuits — free textbooks — Intermediate Advanced A complete multi-volume electronics textbook, free. The reference for when a tutorial doesn't go deep enough. Parts needed: See tutorial for details.

    Project communities

    Hackster.io — Intermediate Large project database across every platform. Quality varies; the highly-starred projects are usually sound. Parts needed: See tutorial for details.

    Instructables — Circuits — Foundation Intermediate Huge quantity, very variable quality. Good for inspiration — verify wiring against a trusted source before building. Parts needed: See tutorial for details.

    Hackaday — Advanced Daily coverage of interesting hardware projects. Not tutorials, but excellent for showing learners what the ceiling looks like. Hackaday.io hosts detailed build logs. Parts needed: See tutorial for details.

    kevsrobots.com — Intermediate Free written robotics courses with open-sourced code. Parts needed: See tutorial for details.

    dronebotworkshop.com — Intermediate Advanced Written versions of every video, with full schematics. Parts needed: See tutorial for details.

    Pi My Life Up — Intermediate Practical Pi server and service projects. Parts needed: See tutorial for details.

    Tom's Hardware — Raspberry Pi — Intermediate Reliable tutorials and honest reviews. Parts needed: See tutorial for details.

    Reference documentation worth teaching learners to read

    Getting a 15-year-old comfortable with primary documentation is one of the highest-leverage things you can do. These are the friendliest starting points:

    • gpiozero recipes — documentation that reads like a project list
    • MicroPython docs — clear, well-organised
    • micro:bit MicroPython docs — deliberately beginner-oriented
    • Raspberry Pi documentation — CC BY-SA, so reusable in your own materials
    • CircuitPython libraries — consistent structure across hundreds of drivers

    The skill to build is scanning — finding the one function you need without reading the page. Model it out loud a few times and most learners pick it up quickly.
